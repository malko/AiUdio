Generation / audio

        

          
          
          
        

        

          
          
          
        

        

          
          
          
        

        
Defaults for every request that does not override them. The sample rate is not a setting: each PCM response announces its own in X-Sample-Rate (24 kHz for the local engines).

        
        

      


      

        Text cleanup
        

          
          
          
        

        
Applied before the text is split (streaming and non-streaming). "off" sends the client's text as-is; "llm" also strips markdown and code fences; emojis have their own setting.

        
A client API key can override these for itself (Access & API keys).

        
        

      


      

        vLLM-Omni (streaming)
        
        
        
        
        
        
        
        
        
Saving applies the whole profile: the gateway recreates the container with this checkpoint and these flags (needs the Docker socket + docker.control), then starts or stops it according to the engine toggle.

        
        

        
The engine toggle is the whole lifecycle: picking vLLM-Omni starts the container (and stops nothing else), going back to the local engine stops it so its VRAM is free again. The service loads a single checkpoint, so pick the model it serves; the gateway routes only that family to it.
